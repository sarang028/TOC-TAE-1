Weighted Stack Validator - installable app

1. Upload this whole folder to any HTTPS host (Netlify Drop, GitHub Pages, Vercel).
2. Open the link in Chrome or Edge and press "Install now".
3. The app gets its own window and logo, and shows up on your desktop / start menu.

Opening index.html straight from disk works as a normal web page, but browsers
only allow installing from an https:// address.

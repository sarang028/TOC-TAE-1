Weighted Stack Validator

A generalized pushdown automaton for bracket languages with unequal match ratios — where one opening symbol can require several closing symbols, or vice versa, instead of the usual 1:1 pairing.

L = { aⁿ b²ⁿ : n ≥ 0 }

Presets

Load a ready-made grammar, then edit freely below.

Grammar rules

Each rule pairs an opening symbol with a closing symbol. Push = tokens placed on the stack per opening symbol. Pop = tokens removed per closing symbol — they must be contiguous and of the same type, or the string is rejected.

openclosepushpop

Input string

Symbols not covered by any rule are rejected. Whitespace is ignored.
